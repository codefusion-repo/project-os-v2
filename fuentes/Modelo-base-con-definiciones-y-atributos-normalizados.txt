| Entidad          | Define                                                                              | Atributos normalizados                                                                                                                |
| ---------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Resolver**     | Entrada única para resolver qué contratos aplican a una solicitud.                  | `id`, `nombre`, `descripción`, `versión`, `manifest_ref`, `policy_ref`, `input_schema_ref`, `output_schema_ref`, `fallback_estado_id` |
| **Actor**        | Superficie desde donde se ejecuta una acción y sus capacidades base.                | `id`, `nombre`, `descripción`, `superficie_capacidad`                                                                                 |
| **Rol**          | Lente profesional aplicado a una tarea.                                             | `id`, `nombre`, `descripción`, `lente_profesional`                                                                                    |
| **Workflow**     | Proceso iterable que coordina pasos, actores, roles, acciones, evidencia y estados. | `id`, `nombre`, `descripción`, `etapa_ciclo_vida`, `orden`                                                                            |
| **WorkflowStep** | Paso ordenado dentro de un workflow.                                                | `id`, `nombre`, `descripción`, `orden`, `objetivo`, `condición_avance`, `condición_repetición`, `condición_bloqueo`                   |
| **Acción**       | Operación concreta que se quiere realizar.                                          | `id`, `nombre`, `descripción`, `tipo`                                                                                                 |
| **Recurso**      | Objeto sobre el que actúa una acción.                                               | `id`, `tipo`, `nombre`, `ubicación`                                                                                                   |
| **Scope**        | Alcance permitido de una tarea.                                                     | `id`, `nombre`, `descripción`                                                                                                         |
| **Fuente**       | Origen de autoridad o verdad.                                                       | `id`, `tipo`, `nombre`, `ubicación`, `nivel_autoridad`, `frescura_requerida`                                                          |
| **Evidencia**    | Información verificable usada para decidir o validar.                               | `id`, `tipo`, `referencia`, `estado_verificación`, `observado_en`                                                                     |
| **Estado**       | Resultado de resolución o ejecución.                                                | `id`, `nombre`, `descripción`                                                                                                         |
| **Límite**       | Restricción obligatoria que no debe romperse.                                       | `id`, `nombre`, `descripción`, `tipo`, `severidad`                                                                                    |
| **Regla**        | Norma que guía conducta o decisión.                                                 | `id`, `nombre`, `descripción`, `condición`, `comportamiento_esperado`                                                                 |
| **Variable**     | Dato dinámico configurable.                                                         | `id`, `nombre`, `tipo`, `valor_default`, `valores_permitidos`                                                                         |
| **Plantilla**    | Estructura reusable para generar prompts, respuestas, reportes o bodies.            | `id`, `nombre`, `tipo`, `formato`, `secciones_requeridas`                                                                             |
| **Artefacto**    | Resultado producido por una acción o workflow.                                      | `id`, `tipo`, `nombre`, `referencia`                                                                                                  |
| **Relación**     | Vínculo formal entre entidades.                                                     | `id`, `origen_entidad`, `origen_id`, `destino_entidad`, `destino_id`, `tipo_relación`, `cardinalidad`, `requerido`, `orden`           |
| **Contrato**     | Especificación formal/versionable de una entidad o relación.                        | `id`, `nombre`, `entidad_tipo`, `versión`, `schema_ref`, `estado`                                                                     |
