# Non-operational templates

These templates shape outputs resolved from `project-os-en/kernel/artifacts.json`. They never grant authority, execute commands, or become live state. Use the artifact's `required_template`; operation prompts remain in `project-os-en/operations/` and optional skills in `project-os-en/skills/`.

`pm-command-bundle.md` is the single canonical source for copy-safe PM command-bundle shape and style. All other files own one artifact form.
