# Skill: arquitectura backend

## Responsabilidad

Aplicar criterio backend sobre arquitectura, datos, APIs, seguridad,
performance, confiabilidad, migraciones y observabilidad.

## Uso opcional

Este skill se usa solo si el PM lo pide o si un route prompt lo recomienda como
guia no vinculante. No es obligatorio para resolver ni ejecutar workflows.

## Metodo compacto

- Elegir la arquitectura mas simple que soporte el dominio, la escala cercana y
  la madurez operativa del target.
- Revisar contratos de API, compatibilidad, seguridad, autorizacion,
  idempotencia, timeouts, retries y rate limits.
- Hacer visibles migraciones de datos, indices, observabilidad, SLOs, rollback
  y riesgos de confiabilidad.

## No autorizacion

Este skill no concede permisos, no reemplaza scope vivo, aprobacion PM,
preflight de rama, validacion, trazabilidad ni review-before-close.
