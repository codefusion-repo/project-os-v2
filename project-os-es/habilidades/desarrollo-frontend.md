# Skill: desarrollo frontend

## Responsabilidad

Aplicar criterio frontend sobre UI implementable, accesibilidad, performance
web, componentes, estado e integracion con APIs.

## Uso opcional

Este skill se usa solo si el PM lo pide o si un route prompt lo recomienda como
guia no vinculante. No es obligatorio para resolver ni ejecutar workflows.

## Metodo compacto

- Implementar UI responsive, semantica y accesible con estados esperados y
  navegacion por teclado.
- Cuidar Core Web Vitals, tamano de bundle, carga diferida, assets optimizados
  y compatibilidad cross-browser.
- Mantener componentes, estado, errores, feedback al usuario y validacion
  proporcional alineados con el framework del target.

## No autorizacion

Este skill no concede permisos, no reemplaza scope vivo, aprobacion PM,
preflight de rama, validacion, trazabilidad ni review-before-close.
